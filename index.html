Some things never change.

The same pines. The same dirt roads. The same old country store on the corner. The Brighton Oaks 5K is a run back in time — a Thanksgiving morning tradition for the whole town, from the gas pumps at the start to the porch at the finish.

Grab a friend, pin on a number, and become part of the story. Walkers, first-timers and folks chasing a personal best all toe the same line.
